# Vibe PPT 模板来源与复刻边界

Vibe PPT 的模板库参考了当前项目已有的版式系统，以及公开的 [Dashi PPT Skill](https://github.com/chuspeeism/dashi-ppt-skill) 风格说明和页面角色设计。

## 当前实现

`lib/template-library.ts` 提供 12 套可直接创建的 Vibe PPT 风格模板。每套模板会生成一份五页的可编辑起始演示，包含封面、叙事结构、指标、图表和结尾页；不同主题还使用不对称分栏、代码控制台、数据大图表、编辑式分栏、极简留白和波形节奏等不同构图，而不是只替换同一套页面的颜色。用户可以继续修改文字、数据、图表、颜色和位置，也可以完整撤销这次模板应用。

模板采用 Vibe PPT 自己的 `PresentationDocument` schema、shape/text/chart 元素和 PPTX 导出链路；没有把外部运行时、HTML 页面或模板清单接入生产包。

## 许可证说明

Dashi PPT Skill 仓库声明使用 AGPL-3.0。Vibe PPT 没有复制该仓库的代码、`layout-manifest.json`、素材或运行时组件，而是依据其公开的风格名称、适配场景、页面角色和布局思想重新实现可编辑模板。因此本文件保留来源与复刻边界，方便后续继续扩展时进行合规复核。
